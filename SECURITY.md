# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within deskloop, please report it responsibly rather than opening a public issue.

Please send an email detailing the issue, reproduction steps, and potential impact to the repository maintainer, or report via GitHub Private Vulnerability Reporting if enabled.

You will receive an acknowledgment within 48 hours, followed by an assessment and patch timeline.
