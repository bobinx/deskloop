# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within deskloop, report it through GitHub
Private Vulnerability Reporting when it is enabled for the repository. Until then,
contact the repository owner privately through the repository's GitHub profile;
do not open a public issue.

Maintainers aim to acknowledge reports within 48 hours, followed by an assessment
and patch timeline.
